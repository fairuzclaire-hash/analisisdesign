## 🌟 Fitur

### Portfolio
- ✅ Hero section dengan animasi
- ✅ About & Philosophy
- ✅ Selected Artifacts
- ✅ Academic Journey per Semester
- ✅ Technical Expertise
- ✅ Career Roadmap
- ✅ Responsive design

### Sistem Tugasku
- ✅ Dashboard per semester (1-8)
- ✅ 16 pertemuan per mata kuliah
- ✅ **Upload multiple files** per pertemuan
- ✅ **Preview file** (gambar, PDF, text)
- ✅ **Download individual** files
- ✅ Progress tracking visual
- ✅ Drag & drop upload
- ✅ Role: Mahasiswa & Dosen

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
